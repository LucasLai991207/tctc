輸入小技巧
標點符號怎麼打？
各種符號輸入的指法：

引號「」
• Windows：Ctrl + [ + ↓選擇，就會直接彈出選字清單。（持續按住 Ctrl，點一下 [ 之後使用方向鍵調整至需要的符號）
• Mac：直接按下鍵盤右上角的符號即可打出

頓號、
• Windows：Ctrl + '（' 為上引號，在 Enter 鍵左邊）。
• Mac：直接按下鍵盤右上角的符號即可打出

冒號：
• Windows：Ctrl + shift + ;（; 為注音ㄤ的按鍵）
• Mac：shift + ;

問號？
• Windows：Ctrl + shift + /（/ 為注音ㄥ的按鍵）
• Mac：shift + /

驚嘆號！
• Windows：Ctrl + shift + 1（1 為注音ㄅ的按鍵）
• Mac：shift + 1

逗號，
• Windows：Ctrl + ,（, 為注音ㄝ的按鍵）
• Mac：shift + ,

句號。
• Windows：Ctrl + .（. 為注音ㄡ的按鍵）
• Mac：shift + .

單詞模式小提醒
打完一個詞會自動換下一個
單詞模式不用按空白鍵！

只要把畫面上反白的那個詞打對，並按下Enter，系統就會自動判定完成、清空輸入框。

如果卡住打不出來，也可以按輸入框旁邊的「跳過」按鈕直接換下一個詞。
